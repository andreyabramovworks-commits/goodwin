# Контекстная проверка v7

| Измерение | Итог | Основание |
|---|---|---|
| Факты | Пройдено в пределах брифа; остаются вопросы заказчику | C1–C4 размечены, рискованные цифры и события не выдуманы. Реестр в editorial-brief.md. |
| Путь к записи | Пройдено для существующей реализации | H1 → расписание → телефон. Форма до ввода сообщает об отсутствии отправки; успешная проверка не выдана за запись. |
| Описание занятий | Пройдено | Управление, техника и практика раскрыты рядом с реальными фотографиями. Нет срока результата или гарантии безопасности. |
| Инструкторы, расписание, телефон | Пройдено | Автоматическая проверка защищённых исходников и четырёх телефонных ссылок. |
| Новости/материалы | Пройдено для evergreen-формата | Шесть фото сопоставлены: четыре статьи и две фотозаметки. Для событийных новостей недостающие факты указаны отдельно. |
| Форма | Пройдено для демо | Пустой ввод, некорректный телефон, ссылки на поля, сохранение значения, повторная проверка, честное сообщение без отправки. |
| Длинные тексты | Пройдено | Все шесть окон открываются сверху; полный текст доступен. Кнопка закрытия остаётся доступной, Tab удерживается, Escape возвращает фокус. |
| Desktop/mobile | Пройдено в эмуляции Chromium | 1440, 1024, 768, 390 и 320 CSS px, реальные снимки экрана. Физический телефон не проверялся. |
| 200/400% reflow | Пройдено в эквивалентной среде | 640/320 CSS px при DPR 2/4 для физической ширины 1280; не выдаётся за ручное управление toolbar zoom. |
| Изменённые интервалы | Пройдено | line-height 1.5, paragraph spacing 2em, letter spacing .12em, word spacing .16em. После исправления min-width:0/переносов ни текст, ни элементы не выходят за ширину 320. |
| Шрифт | Пройдено | Локальный Manrope variable загружается с кириллицей; OFL сохранён. Нет обязательного Google Fonts-запроса. |
| Reduced motion | Пройдено | Атмосфера отключается, все шесть материалов доступны в статическом выборе. |
| Отказ enhancement-модуля | Пройдено | Исходные карточки остаются; полный текст материала открывается нативным обработчиком. |
| Impeccable type scan | Осталось объяснённое предупреждение | Один эвристический tiny-text 11px в исходном слое; в фактическом computed-style обходе видимого текста 11px не осталось. |

Доказательства: verification.json и локальные `qa/v7-verification.json`, `qa/v7-readers-final.json`, `qa/v7-type-findings.json`, изображения desktop/mobile/article/form/zoom/text-spacing. Общая проверка не заявляет полной WCAG-сертификации и не заменяет проверку юридических текстов клубом.

Не решается редактурой: реальные адрес/цены/оснащение, утверждённые условия, backend отправки и ответственный за запись, права и факты для конкретных событийных новостей.
