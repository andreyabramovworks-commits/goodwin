# Гудвин — версия 7

Тексты и типографика готового лендинга клуба «Гудвин». Дизайн v6 сохранён, инструкторы, расписание и телефон не переписаны.

Версии разделены: `main` и тег `v6` — одобренная версия до редактуры; ветка и тег `v7` — новая редакция. [Скачать v6](https://github.com/andreyabramovworks-commits/goodwin/archive/refs/tags/v6.zip), [скачать v7](https://github.com/andreyabramovworks-commits/goodwin/archive/refs/tags/v7.zip). На удалённом сервере ничего не менялось.

## Запуск локально

```powershell
npm ci
npm start
```

Откройте `http://127.0.0.1:4178`.

Сайт статический: для публикации на сервер достаточно разместить содержимое этой папки в директории сайта. Видео и фотографии уже находятся в `assets/media`.

## Что содержит версия

- реальное расписание: вторник и четверг 18:00–20:00, суббота 12:00–14:00;
- телефон для записи: +7 (908) 011-61-74;
- реальные фото и профили инструкторов;
- локальный видеоплеер для материала о FPV-съёмке;
- адаптивная вёрстка, анимации с уважением к настройке reduced motion.


## Локальные правки интерфейса

Открыть: http://127.0.0.1:4178. Файлы уже собраны, для просмотра повторная сборка не нужна. Используйте HTTP-сервер: модули не предназначены для просмотра через file://.
При необходимости запустить сервер: `npm start`.
После изменения `src/enhancements.jsx` или компонента карусели выполнить `npm run build`.

- Инструкторы: большой портрет и биография выбранного преподавателя, переключение между тремя профилями. Исходные фотографии, имена и тексты сохранены.
- Материалы: четыре статьи по оригиналам Максима Музыканта и две фотозаметки без выдуманных событий. Circular Carousel, отражения и ручное переключение сохранены.
- Логотипы: исходный статичный вариант. Электрическая анимация удалена по последней правке.
- Окна: нативный диалог, корректная сетка, отдельная кнопка закрытия, одна область прокрутки, Escape, закрытие по фону, удержание и возврат фокуса, устойчивость к быстрому повторному открытию.
- Видео открывается с обычными локальными HTML5-контролами; ошибочное подключение старого модуля видеоплеера убрано.

Проверка: `verification.json`, снимки реальных состояний — `qa/`.
Источники и лицензии: `THIRD_PARTY.md`; решения и границы — `IMPLEMENTATION.md`.
## Тексты и проверка

`npm run check` проверяет точное сохранение исходного HTML разделов инструкторов и расписания, телефон, шесть материалов и честный статус формы. `npm run build` собирает готовые локальные assets.

- `content/client-original.md` — исходные сообщения заказчика.
- `content/editorial-brief.md` — факты, источники, структура, сопоставление фото/текстов, вопросы заказчику, шрифтовые роли.
- `content/text-map.md` и `.json` — карта 156 исходных элементов и новых текстов с редакторскими решениями.
- `content/final-copy.md` — реализованные тексты страницы, всех статей и состояний формы.
- `content/stories.json` — редактируемые статьи и фотозаметки; внутренние примечания не выводятся на странице, но доступны в репозитории.
- `typography.css` — единая локальная Manrope с кириллицей, размеры, веса, интервалы и адаптивная композиция.
- `content/protected-source.json` — точные исходники защищённых разделов v6 для проверки.

**Отправка формы не подключена.** До подключения реальная запись проходит по телефону клуба. Форма сообщает это до ввода данных и позволяет только проверить заполнение/выбор дня. Она не отправляет данные и не обещает обратного звонка. Адрес, стоимость, оснащение занятий и официальные документы требуют подтверждения клуба.

Локальные снимки desktop/mobile, ошибки формы, статьи, масштаб 200/400% и увеличенные интервалы — в `qa/` (игнорируется Git). Фактически выполненные проверки — `verification.json`. Отдельные папки v6/v7 и теги позволяют сравнить и восстановить каждую версию.
