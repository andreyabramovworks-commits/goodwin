# Гудвин — клуб дрон-рейсинга

Локальная версия 6 одностраничного сайта клуба «Гудвин».

## Запуск локально

```powershell
npm install
npm start
```

Откройте `http://127.0.0.1:4177`.

Сайт статический: для публикации на сервер достаточно разместить содержимое этой папки в директории сайта. Видео и фотографии уже находятся в `assets/media`.

## Что содержит версия

- реальное расписание: вторник и четверг 18:00–20:00, суббота 12:00–14:00;
- телефон для записи: +7 (908) 011-61-74;
- реальные фото и профили инструкторов;
- локальный видеоплеер для материала о FPV-съёмке;
- адаптивная вёрстка, анимации с уважением к настройке reduced motion.


## Локальные правки интерфейса

Открыть: http://127.0.0.1:4177. Файлы уже собраны, для просмотра повторная сборка не нужна.
При необходимости запустить сервер: `npm start`.
После изменения `src/enhancements.jsx` или компонента карусели выполнить `npm run build`.

- Инструкторы: большой портрет и биография выбранного преподавателя, переключение между тремя профилями. Исходные фотографии, имена и тексты сохранены.
- Новости: Circular Carousel из React Bits, подписи на фото, тени и затухающие отражения, две центральные кнопки «назад/вперёд». Автовращение отключено. На телефоне — крупные карточки со свайпом.
- Логотипы: исходный статичный вариант. Электрическая анимация удалена по последней правке.
- Окна: нативный диалог, корректная сетка, отдельная кнопка закрытия, одна область прокрутки, Escape, закрытие по фону, удержание и возврат фокуса, устойчивость к быстрому повторному открытию.
- Видео открывается с обычными локальными HTML5-контролами; ошибочное подключение старого модуля видеоплеера убрано.

Проверка: `verification.json`, снимки реальных состояний — `qa/`.
Источники и лицензии: `THIRD_PARTY.md`; решения и границы — `IMPLEMENTATION.md`.
Текущая работа локальная; публикация на сервер и push в GitHub не выполнялись.
